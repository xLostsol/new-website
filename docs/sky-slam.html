Featured game: Sky Slam

I built the code for Sky Slam, a multiplayer game published under Ember Games. I worked on it in March–April 2026 as part of my broader portfolio of nine Roblox games.

Typed Luau and reactive UI

I built the games in strictly typed Luau with reactive cross-platform UI and real-time game-state synchronization. The UI works across desktop and mobile, alongside custom cutscenes and animations.

AI-assisted development

I integrated Claude and Codex into Roblox Studio and Blender through MCP for in-editor development and review.

Automated releases

I automated releases through the Roblox Open Cloud API, pushing updates, game passes, and badges without manual dashboard work.
