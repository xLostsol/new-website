Typed Luau codebase

I built a modular, strictly typed Luau codebase with interfaces between game systems and real-time game-state synchronization. The types make each system's expectations explicit and help catch mismatches while writing code.

Reactive UI

The UI responds to game-state changes and real-time data updates, including leaderboard tracking, and works for both desktop and mobile players.

AI-assisted development

I connected Claude and Codex to Roblox Studio through MCP servers for in-editor generation and type-aware code review.
