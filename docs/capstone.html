Benchmark dashboard

I built a dashboard in JavaScript and Node.js scoring 65 runs of GitHub Copilot, Claude Code, Codex CLI, and Antigravity. It consolidates 2,300 evidence files into one side-by-side comparison.

Scoring with traceable deductions

I implemented a scoring engine across five categories: functionality, security, code quality, token use, and human intervention. Every deduction is itemized, so each grade can be traced to the exact failed check.

Sandboxed app replay

I created a sandboxed in-browser replay that runs the original app beside each agent’s version, surfacing API route changes and code diffs. I presented the results to a Microsoft sponsor.
