# joseph.jbressani.org

Source for my personal website, [joseph.jbressani.org](https://joseph.jbressani.org).

## Structure

- `docs/`: the live site, published by GitHub Pages from the `main` branch
- `site/`: page content and the shared layout
- `scripts/`: build and check scripts

The HTML pages in `docs/` are generated from `site/` with `npm run build`.
