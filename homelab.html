Compute and workload isolation

I built a Proxmox host running media, game, and network services side by side. Each service is isolated in its own container or VM while sharing a storage pool.

Network access controls

I closed every inbound port to the internet and moved remote access to a private Tailscale mesh. Device access policies limit each device to what it needs.

This makes remote access dependent on authorized mesh devices. In exchange, services do not need public inbound ports just to be reachable remotely.

Backup and recovery

I automated nightly backups and verified them with a full restore. That tests the recovery path as well as the backup job itself.

Remote wake automation

A Python relay lets me wake my desktop from my phone over cellular. The relay is hardened with dropped privileges, source-address validation, and rate limiting.

Earlier deployment: Minecraft server

I also configured and deployed a Minecraft server on Ubuntu Server, including external access, networking configuration, server optimization, and user management. That earlier setup used port forwarding; the current homelab uses private mesh access.

What this project demonstrates

Operating services beyond the initial setup: access boundaries, workload isolation, automation, and recoverability.
