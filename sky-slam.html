Keeping game systems in sync.

Multiplayer software connects several moving parts: game state, user interfaces, live updates, and leaderboards. Sky Slam brings those systems together across desktop and mobile.

A modular, typed codebase.

I built a strictly typed Luau codebase with interfaces between game systems. Those interfaces make expectations explicit and help surface type mismatches during authoring. They complement runtime testing; they do not replace it.

Reactive UI across platforms.

The UI responds to game-state changes and real-time data updates, including leaderboard tracking. The cross-platform interface supports both desktop and mobile players.

AI tooling in the development process.

I connected Claude and Codex to Roblox Studio through MCP servers for in-editor generation and type-aware code review. The project's type definitions supplied a concrete contract for that workflow.

What this project demonstrates

Bringing typed systems, reactive interfaces, and multiplayer state together in a published product.
